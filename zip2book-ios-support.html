Zip2Book for iOS

Support / サポート・最終更新日: 2026年5月28日

アプリについて

Zip2Book for iOSは、圧縮ファイル、PDF、複数の画像を取り込み、 iPhoneまたはiPad上の本棚として読むためのアプリです。対応する ファイルを選択すると、ページ画像、表紙、読む向き、読書位置などを 端末内に保存して管理できます。

対応ファイル

iOS / iPadOS版は、ZIP / CBZ、RAR / CBR、TAR / CBT、 TAR.GZ / TGZ、TAR.BZ2 / TBZ、TAR.XZ / TXZ、PDF、JPEG、PNG、 WebP、HEIC / HEIF画像の取り込みに対応しています。

広告と無料利用

本アプリは無料で利用でき、Google AdMobによる広告が表示されます。 リワード広告を視聴すると、一定時間広告表示を停止できます。 現在のiOS版には、App内課金、サブスクリプション、有料アンロック、 外部決済はありません。

保存データ

取り込んだ本、ページ画像、表紙、ページメモ、シリーズフォルダ、 読む向き、読書進捗などは端末内に保存されます。アプリを削除すると、 端末内の保存データも削除される場合があります。

プライバシー

プライバシーポリシーは 専用ページ を参照してください。Android版とは別に、iOS / iPadOS版の取り扱いを 説明しています。

お問い合わせの際は、アプリ名、利用端末、iOS / iPadOSのバージョン、 ファイル形式、問題が発生した操作を可能な範囲でお知らせください。

GitHub Issuesは公開ページです。氏名、住所、電話番号、メールアドレス、 決済情報、取り込んだ本や画像そのものなどの個人情報・非公開情報は 書き込まないでください。
