いかさまルーレット

Support / 利用上の注意・最終更新日: 2026年5月7日

アプリについて

いかさまルーレットは、パーティーや順番決めで使う娯楽・演出用の ルーレットアプリです。好きな項目を追加し、重みを調整したり、 設定画面から止まる項目を固定したりできます。

無料利用・課金について

本アプリは無料で利用できます。現在、アプリ内課金、 サブスクリプション、有料アンロック、外部決済はありません。

利用上の注意

本アプリは娯楽・演出用です。実際の賭博、賞品抽選、金融取引、 公平性が必要な意思決定には使用しないでください。

本アプリの提供、アップデート、サポート内容は、OS、 App Storeポリシー、開発環境の変更などにより、予告なく変更または 終了する場合があります。将来のすべてのOS・端末での動作を保証する ものではありません。

保存データ

入力した項目、重み、プリセット、設定は端末内に保存されます。 アプリを削除すると、端末内の保存データも削除される場合があります。

広告とプライバシー

本アプリはGoogle AdMobによる広告を表示します。地域や設定に応じて、 広告同意フォームやiOSのトラッキング許可ダイアログが表示される場合が あります。許可しない場合でも、ルーレットの基本機能は利用できます。

プライバシーポリシーは 専用ページ を参照してください。

お問い合わせ

不具合やサポートが必要な場合は、公開サポート窓口の GitHub Issues からお問い合わせください。

お問い合わせの際は、アプリ名、利用端末、iOS / iPadOSのバージョン、 不具合の内容を可能な範囲でお知らせください。

GitHub Issuesは公開ページです。氏名、住所、電話番号、メールアドレス、 決済情報などの個人情報は書き込まないでください。
